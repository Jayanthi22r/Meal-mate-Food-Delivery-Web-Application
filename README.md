🍽️ Meal-Mate – Food Delivery Web Application

Meal-Mate is a full-stack food delivery and restaurant management web application built using Python (Django). It allows users to browse restaurants, view menus, add items to cart, and place orders seamlessly, while providing admins with complete control over restaurant and menu management.

🚀 Features
User registration and secure login authentication
Browse restaurants and view detailed menus
Add to cart and manage selected items
Smooth checkout and order placement system
Admin panel for managing restaurants, menus, and orders
Session-based cart management
Responsive and user-friendly UI
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python, Django
Database: SQLite / MySQL
Tools: VS Code, MySQL Workbench
🎯 Project Goal

The main aim of Meal-Mate is to simplify food ordering by providing a fast, reliable, and user-friendly online platform that connects customers with restaurants efficiently.
